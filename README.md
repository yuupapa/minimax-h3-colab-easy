# MiniMax H3をColabで動かすAIセットアップキット

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/yuupapa/minimax-h3-colab-easy/blob/main/MiniMax_H3_Easy_Colab.ipynb)

MiniMax H3で文章から動画、または始点画像から動画を作るための、Google Colab用セットアップキットです。Claude・CodexなどのAIへこのURLを渡し、READMEと[AGENTS.md](AGENTS.md)に沿って操作を依頼できます。ブラウザ操作機能がないAIの場合は、本人がColabで手動実行してください。

**Macへモデル、Python、uv、Gitを入れる必要はありません。** モデルと依存はColabのクラウドVMへ取得します。Googleへの本人ログイン、対応GPUと既存CU、ライセンス・利用条件の確認は必要です。URLだけで全環境の完全自動動作を保証するものではありません。

## 対応範囲

| 用途 | この版の状態 |
|---|---|
| Text-to-Video | 配布版で5秒1本のGPU生成・保存・全編デコード・GPU終了を確認 |
| Image-to-Video | 始点画像1枚＋動きの文章。配布版で5秒1本のGPU生成・保存・全編デコード・GPU終了を確認 |
| Reference-to-Video | 未対応。別Ref2VA重みと互換性検証が必要。選択すると取得前に停止 |
| 解像度・秒数 | **960×544、16:9固定。解像度選択なし。** 5秒を実測。6秒は設定可能だが未実測 |

公開H3 BaseのFL2VAとLightX2V Turbo v0.1の4-step構成です。H3 API専用のフル2K機能は含みません。**ネイティブ1920×1080生成はできません。** 固定SGLangでは720指定も1280×704、1080指定も1344×768になります。現在はその選択機能もありません。[寸法と検証範囲](docs/VALIDATION.md)

## AIへ渡す依頼文

```text
このリポジトリのREADMEとAGENTS.mdを読んで、Google ColabでMiniMax H3をセットアップしてください。MacやローカルPCへモデルを取得せず、追加購入・新規有料契約・自動課金・Drive全体マウントをしないでください。既存CUを確認し、上限3CUを目安にまず5秒動画を1本だけ作ってください。ログインや規約・ライセンスの判断は本人へ引き継ぎ、必要な実行・送信権限を確認してください。動画を端末へ保存して全編デコードと品質を確認し、最後にGPUを削除して残CU・使用率0・稼働0件を報告してください。
```

画像から作る場合は、使う画像とColabへの送信許可を具体的に追加してください。40本の一括生成はこの依頼文にも本キットの初回作業にも含みません。

## 初めて使う人の操作

1. 上の「Open in Colab」を開き、既存のGoogleアカウントでログインします。ローカルのノートブックから使う場合は「ファイル → ノートブックをアップロード」で `MiniMax_H3_Easy_Colab.ipynb` を選びます。この1ファイルは自己完結しています。
2. H3の[ライセンス全文](licenses/MINIMAX-H3-COMMUNITY.txt)と[利用条件の案内](docs/LICENSING.md)を読みます。今回の利用地域・商用条件・Acceptable Use Policyを本人が確認し、`LICENSE_ACCEPTED` と `ELIGIBLE_USE_CONFIRMED` をオンにします。
3. 「ランタイムのタイプを変更」でA100・ハイメモリを選び、接続します。実際に**VRAM80GB、システムRAM約167GB**が割り当てられたことと残CU・CU/時をリソース画面で確認します。フォームの `CU_REMAINING` と `CU_PER_HOUR` に実際の表示を入れます。初回は1本・5秒、`CU_BUDGET=3`が目安です。
4. T2Vなら文章を入力し、入力→セットアップ→生成→ZIP保存の順で実行します。セットアップの `SETUP_OK` を待ってから生成してください。入力後の「すべてのセルを実行」も使えます。終了セルは初回に保存確認で停止します。
5. I2Vなら `GENERATION_MODE=Image-to-Video`、画像・動画各1枚/本を選びます。画像の権利・写った人物の同意・元画像のColab送信を確認して `IMAGE_USE_CONFIRMED` をオン。`UPLOAD_FIRST_FRAME` をオンにし、**入力セルだけ**を実行して画像を選びます。表示された内容と向きを確認して `IMAGE_CONTENT_CONFIRMED` をオン、`UPLOAD_FIRST_FRAME` をオフにし、入力セルだけ再実行。その後セットアップへ進みます。初回は横長16:9の静止画PNG/JPEG/WebP（20MiB以内）を推奨します。別比率はトリミングされ得ます。
6. ZIPのダウンロードが完了し、端末で動画が開けることを確認します。`SAVED_TO_MY_DEVICE` をオンにし、**終了セルだけ**を再実行。Colabで**使用率0・稼働0件**を確認します。終了セルが動かない場合は「ランタイム → ランタイムを接続解除して削除」。ブラウザを閉じるだけではGPU停止の確認になりません。

Colabの本数・秒数プルダウンにはinteger型の警告が表示される場合があります。配布版は既定の1本・5秒で検証しました。2本・6秒へ変更したフォームは配布版では未検証です。画像選択のタイムアウトや保存失敗は[トラブル対応](docs/TROUBLESHOOTING.md)へ。

## 必要な環境・費用

対象はColab Linux x86_64、**A100 80GB、RAM約167GB**です。固定CUDA13系依存のためNVIDIAドライバ580以上が必要です。T4、L4、A10040GB、RAM不足では取得前に停止します。初回はモデル約134GiB＋依存を取得。大容量scratchに180GiB以上、別ディスクの `/content` に25GiB以上の空きを確認します。同じディスクなら合計205GiB以上が必要です。scratchが無い環境の代替保存先は静的検証のみです。

GPU接続中は導入・取得・待機もCUを消費します。同じVMではキャッシュを再利用できますが、VMを削除すると再取得が必要です。GPUの割当は有料プランでも保証されません。[Colab公式FAQ](https://research.google.com/colaboratory/faq.html#resource-limits)

Google AI Proの200CCU特典には年齢、ファミリー管理者、試用契約を除くなどの条件があります。特典の数値と実際の残量は別です。同じアカウントのColab画面を確認してください。[Google公式案内](https://support.google.com/googleone/answer/14534406?hl=en) 対応GPU/CUが無ければ追加購入せず停止します。APIキー・HFトークン、Driveマウント、外部トンネルは不要です。

**上限CUは時間に換算した停止目安で、請求保証ではありません。** 入力した使用率から上限時間を算出し、85%の時点で処理を止め、100%でVM終了を要求するタイマーを設定します。入力前のGPU待機、使用率の変化、請求表示の遅れ、通信失敗の影響があります。AI・本人は残量を監視し、終了を画面で確認してください。タイマー満了による自動終了自体はGPU実機では未検証で、未保存ファイルが失われる場合があります。終了セルの統合結果は[検証記録](docs/VALIDATION.md)に記載しています。

## 実測結果

配布版を別のクリーンColabセッションで試験しました。モデルは各試験で1回読み込み、A10080GB・RAM167.05GB、torch_sdpa・層単位CPU offload、5秒指定です。

| 処理 | T2V（2026-10-11） | I2V（2026-10-12） |
|---|---:|---:|
| モデル初期化 | 199.132秒 | 205.243秒 |
| 1本の生成 | 92.688秒 | 106.352秒 |
| 形式 | 960×544・24fps | 960×544・24fps |
| コンテナの長さ | 5.175秒 | 5.175秒 |
| セッションCU表示差 | 2.81CU | 1.87CU |

映像・音声の全編デコード、端末への保存、GPU使用率0・稼働0件を確認しました。T2VのCUにはI2V画像選択の待機も含みます。I2VのCUにも導入・取得・初期化・保存等を含み、生成単体のCUではありません。表示更新は遅れる場合があります。速度・CU・品質を保証しません。I2V画像反映の観察、6秒・別GPU・高解像度・40本・未確認の終了枝は[検証記録](docs/VALIDATION.md)を参照してください。元画像・試験動画・個人アカウント情報は公開repoに含みません。

## 再開と安全な保存

同じ入力の完了済み動画は再生成せず既存ファイルを返します。新しい文章や失敗後の再試行は、保存と診断後に本人が許可し、`NEW_RUN` をオンにして入力セルを実行。許可は生成セルで1回だけ消費されます。失敗しても自動再試行しません。最大2本を同じ生成セル内で順に生成する経路がありますが、配布版の実測は1本ずつです。

元画像と正規化PNGはクラウドVMにだけ保存され、VM削除で消えます。元画像にはEXIF等が含まれ得ます。画像を出力ZIPへ自動同梱せず、Drive・GitHub・Libraryへ自動公開しません。プロンプト・動画等を別の保存先へ送る場合は、その内容と送信先の許可を確認してください。
