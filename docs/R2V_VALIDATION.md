# R2V720の実測と統合候補の検証範囲

2026-10-12、A10080GB・RAM167.05GiB・driver580.82.07の別Colab VMで、参照静止画1枚・5秒指定・動画1本を生成した。T2V/I2VのSGLang環境は変更していない。

## 実測した構成と出力

H3固定revisionの `transformer_ref`、Ref2VA Turbo v0.1 BF16、alpha8/scale1/fuseなし、ModelTC固定版 `match`、4回のTransformer評価を使用。MiniMaxH3Schedulerへ終端sigmaを含む5点を渡す。参照は `references` へ渡し、I2V用 `image` / `images` は使用しない。Hopper専用FlashAttention3は指定していない。

| 項目 | 実測 |
|---|---:|
| 重み取得・LoRAハッシュ照合 | 367.24秒 |
| パイプライン読込区間 | 9.76秒 |
| 参照encode・推論・復号の合計 | **180.00秒** |
| 原寸MP4書出し | 9.05秒 |
| 実際のTransformer評価 | 4回 |
| CUDA peak allocated / reserved | 76.35 / 78.42GiB |
| プロセスpeak RSS | 77.09GiB |
| 生成寸法 | **1280×736** |
| 納品寸法 | **1280×720** |
| フレーム / FPS | 124 / 24 |
| 映像 / 音声・コンテナ長 | 5.166667 / **5.175秒** |
| 一連の試験のCU表示差 | 2.70CU |

CUDAへの転送・初回初期化の一部は推論区間に含まれ得る。9.76秒をSGLangの初期化時間と直接比較しない。CUは本人確認の待機・別セッションへの再開・取得・保存を含む画面残量の差で、生成単体の課金ではない。請求表示の遅れと環境差があるため、速度・費用を保証しない。

1280×736から上下8pxずつ中心クロップし、再エンコードして1280×720にした。拡大・縦横の歪みはないが、縦画角の約2.17%と再圧縮分を失う。1280×704を720pとは呼ばない。原寸と納品版の両方で全映像・音声デコードに成功し、保存ZIPのCRCと端末側の全デコードも確認した。モデル重み・参照画像・試験動画は公開ソースに含めない。

茶トラの毛色・縞・立った尾を引き継ぎ、背景が木のベランダから砂浜・海へ変わった。全124フレームで歩行とカメラ方向への顔の動きを確認した。模様・体格・足・輪郭には変化があり、人物・商品の完全一致を保証する結果ではない。尾の一部は画面外。音声はデコード済みだが聴感評価は未実施。

## 実機で確認したことと、今回の統合差分

実機では独立venvの依存解決・同期、固定Diffusers APIのimport、LoRAハッシュ、Ref2VA生成、4評価、原寸/720pの全デコード、保存、Colabメニュー削除後の使用率0・稼働0を確認した。参照用v0.1は544p学習なので、今回の1280×736成功を他の参照・環境へ一般化しない。76GiBを超えるVRAMを使う構成である。

統合候補は実機で使った67依存の `requirements-r2v.lock` を原文・同じSHA256で固定し、実行時の再解決をなくした。GPU接続後、最初の入力までの経過分を時間枠から差し引く制御、参照の寸法記録検査、実際のプロンプト表示、別ノートブックへの案内を加えた。**これらの統合差分はオフライン検査のみで、追加GPU再試験は行っていない。** `r2v_native.py` とModelTC同梱ソースは実機版から変更していない。

**新しいR2V終了補助セルと、時間上限による自動終了はGPU実機未検証。** 終了補助は既定で無効。保存後または失敗時は、必ずColabの「ランタイム → ランタイムを接続解除して削除」を実行し、リソース画面で使用率0・稼働0を確認する。補助セルの成功表示、タイマー開始、プロセス終了、ブラウザを閉じることをGPU停止の証拠にしない。

今回の実機はノートブックの入力後に接続開始時刻へ期限を補正し、生成直前に承認済みプロンプトを明示した。配布候補では経過分のフォームと実際のプロンプト表示へ一般化した。Colabフォームの表示値が実行値へ確定しない場合があるため、表示された「この文章で生成します」を本人/操作者が照合する。

未実測は、R2V終了補助・期限満了終了、544p拡大版、6秒、複数参照、人物・商品、他GPU、40本連続生成。新しい試験はその目的・本数・上限CUの承認がある場合だけ実施する。
